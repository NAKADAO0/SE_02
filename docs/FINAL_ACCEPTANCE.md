## 4. 静态语义复核

没有自动执行模型生成代码。人工阅读实际代码与审查报告，确认以下逻辑：

| 任务 | 复核点 | 静态结论 |
| --- | --- | --- |
| 求和 | 空输入、负数、多个整数；不修改输入 | 累加器从 0 开始并遍历输入，满足描述 |
| 括号配对 | 空串、`([{}])`、`([)]`、多余闭括号及忽略文字 | 栈和配对表正确处理这些分支 |
| 顺序去重 | `[2,1,2,3,1]`、空列表；原输入不变 | 用 set 记录已见元素并追加到新列表，保留首次顺序 |
| 缺陷修复 | 空列表初稿返回 None | 报告指出问题，v2 改为 sum(values)，复审通过 |

这些证据验证本次样例，不构成任意代码的形式化正确性证明。

## 5. 审查与问题修复

独立代码审查发现并修复：JSON 转义凭据可能绕过输出保护；默认人类输出遗漏持久化错误诊断。两项均先加入回归复现，再修复并由独立审查复核。另补充 Python 3.11 缺少 Path.is_junction 时的真实 Windows junction 回归，先复现再修复解析边界，避免越界打包；当前两项 junction 测试均通过。其他核心版本关系、修复边界与失败终态测试继续通过。

## 6. 打包与复现

交付包为 `deliverables/SE_02-source.zip`，旁边的 `.sha256` 提供校验值。包内 MANIFEST.json 逐文件记录大小和 SHA256；固定排序、时间和权限，可在同一压缩环境重复生成相同字节。

只打包白名单源码、文档、测试、样例与脱敏 release 证据；排除 .env、真实密钥、虚拟环境、缓存、Git 元数据和私密 runs。包小于 200 MiB，并已从独立解压目录执行例行测试和 CLI 演示。

重建命令：`python scripts/build_release.py --output deliverables/SE_02-source.zip`。安装、验证和解压步骤见 [打包说明](PACKAGING.md)，使用方法见 [CLI 说明](CLI_GUIDE.md)。
