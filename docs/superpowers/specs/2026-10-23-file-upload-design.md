# Web 文件上传调整

用户要求网页以待测文件上传为唯一入口，API和模型与原CLI一致。本次保留既有三栏风格，将需求输入与Mock选择替换为.py文件选择。固定复用config.example.toml和SE02_API_KEY，不引入浏览器端密钥或独立模型设置。

UTF-8源码限制32 KiB，服务端验证文件名、大小、空值和二进制内容。原文保留为v1 CodeArtifact，Workflow通过可选initial_code从上传节点进入审查，再使用既有修复/复审循环。CLI原行为保持兼容。仅做模型静态分析，不执行上传代码。

验收包括：无coder模型调用、v1逐字符保留、上传输入拒绝、历史恢复、CLI配置一致性、实际DeepSeek浏览器端到端及窄屏检查。完成后更新文档、截图和源码包，提交远端，并保留本机运行服务供查看。
