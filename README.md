# SE_02：三 Agent 代码审查工作流

## 计划中的演示方式

先实现命令行入口及离线 Mock 演示，再接入真实模型。Mock 用于验证调度与消息协议；真实模型运行用于验证 Agent 的实际生成、审查和修复能力，两类结果分别标记。

本轮没有可运行程序，因此暂不提供启动命令。实现后补充经过实际验证的安装、配置和运行方法。
